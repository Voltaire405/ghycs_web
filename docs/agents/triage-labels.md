# Etiquetas de triage

Las skills hablan en términos de cinco roles canónicos de triage. Este archivo mapea esos roles a los strings de etiqueta que realmente usa el issue tracker de este repo.

| Etiqueta en mattpocock/skills | Etiqueta en nuestro tracker | Significado                                       |
| ----------------------------- | --------------------------- | ------------------------------------------------- |
| `needs-triage`                | `needs-triage`              | Un mantenedor debe evaluar este issue             |
| `needs-info`                  | `needs-info`                | A la espera de más información de quien lo reportó |
| `ready-for-agent`             | `ready-for-agent`           | Totalmente especificado, listo para un agente AFK |
| `ready-for-human`             | `ready-for-human`           | Requiere implementación humana                    |
| `wontfix`                     | `wontfix`                   | No se va a atender                                 |

Cuando una skill mencione un rol (por ejemplo, "aplica la etiqueta de listo para AFK"), usa el string de etiqueta correspondiente de esta tabla.

Los nombres de las etiquetas se mantienen en inglés a propósito: son identificadores del tracker, no prosa. Edita la columna derecha si algún día usas otro vocabulario.
