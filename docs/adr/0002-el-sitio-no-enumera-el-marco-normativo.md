# El sitio no enumera el marco normativo de forma exhaustiva

Cada estándar de habilitación arrastra su propia normatividad, y el conjunto es demasiado extenso para especificarlo completo. El sitio nombra solo las normas ancla —Resolución 3100 de 2019 y Decreto 780— y explica que el marco aplicable se determina por servicio y por estándar; no publica un listado que pretenda ser completo.

La razón no es pereza editorial: una lista de normas en un sitio de habilitación se desactualiza sola y compromete al gestor con un alcance que no controla, porque las normas cambian sin avisarle. Determinar el marco de un prestador concreto es precisamente parte del servicio que se vende, no información que se regala en una página.
